# Employee Payroll Management System

## Project Overview

Employee Payroll Management System is a web-based application developed to manage employee details and payroll information efficiently.

## Technologies Used

* Java
* Spring Boot
* SQL / MySQL
* HTML
* CSS
* REST API

## Features

* Add employee details
* View employee details
* Update employee details
* Delete employee details
* Manage payroll information
* Database integration
* REST API

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or Spring Tool Suite.
3. Configure the database connection.
4. Create the required database.
5. Run the Spring Boot application.
6. Open the application in your browser.

## Project Purpose

This project was developed to gain practical experience in Java, Spring Boot, SQL, REST APIs, and web application development.
